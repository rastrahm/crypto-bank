# Portfolio — Crypto Bank Vault

Página estática del módulo 02 (mismo modelo visual que `01-erc20/portfolio`).

## Ver local

```bash
cd portfolio
python3 -m http.server 8080
# http://localhost:8080/?lang=es
# http://localhost:8080/?lang=en
```

O abrir `index.html` en el navegador.

## Contenido

- Contexto + 3 pilares (vault / gas / SWC)
- Métricas de gas (deploy, withdrawETH, depositERC20, withdrawERC20)
- Matriz SWC resumida + informativos
- Fases 0–6 + campañas A–E
- Links GitHub / GitLab

Traducción ES ↔ EN vía `i18n.js` (toggle en la nav).
